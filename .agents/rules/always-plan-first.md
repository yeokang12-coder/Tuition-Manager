# 先看计划再按按钮执行 (Always Plan & Provide Clickable Button Before Executing)

1. **禁止未授权修改**：在对项目中的任何文件进行创建、修改、删除，或运行具有修改性质的命令之前，**严禁**直接执行。
2. **先展示清晰计划**：必须先整理修改方案（写入或更新 `implementation_plan.md` 并简要说明修改内容）。
3. **提供聊天窗内直接可点的按钮**：每次展示完计划后，必须调用 `ask_question` 工具，在对话框底部弹出可点击的确认选项（例如：`(Recommended) ✅ 确认计划，立即开始执行 (Proceed)`），让用户无需打字、直接点击按钮即可授权执行。
4. **等待用户点击确认后才动手**：只有当用户点击确认按钮后，才开始修改代码、重新编译和重启服务。
