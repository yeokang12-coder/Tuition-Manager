# 补习课时与对账卡片助手 (Tutor Receipt Maker) 🇲🇾

专为马来西亚补习老师与独立教师量身打造的**课时管理、考勤打卡与精美收费对账卡片生成系统**。

---

## ✨ 核心特性

1. **零配置本地持久化**：
   - 采用 Node.js 24 原生内置 SQLite（`tutor_receipt.db`）单文件数据库。
   - 数据完全保留在您的电脑本地，不依赖第三方云端，隐私安全、永不掉单。
2. **手机与电脑多端自适应**：
   - 响应式现代界面，电脑大屏与手机小屏均自适应。
   - 支持移动端底部单手快捷操作栏，支持添加为手机桌面 PWA 快捷方式。
   - 在同一个 Wi-Fi 网络下，手机浏览器直接输入电脑局域网 IP（如 `http://192.168.x.x:3001`）即可直接打卡和开单。
3. **针对大马补习场景设计**：
   - 默认马币结算（RM / MYR）。
   - 贴心支持配置 **DuitNow 账号**、**马来西亚各大银行**（Maybank, CIMB, Public Bank 等）及 **收款二维码**。
4. **直观日历与智能规律排课**：
   - 月历与列表双重视图。
   - 支持设置固定每周课程规律，一键“自动按规律排课”自动铺满整月课时。
   - 课后一键考勤打卡：`正常出勤`、`请假调课`、`补课`、`缺席`，出勤直接关联费用核算。
5. **极速高颜值对账卡片 (Receipt Maker)**：
   - 选择学生与月份，自动拉取当月所有已上课程明细与金额。
   - 支持增减课时、添加教材复印费或优惠减免。
   - 实时预览排版考究、极具美感的**长图对账收据**。
   - 🚀 **一键复制图片到剪贴板**：直接在电脑/手机上的 WhatsApp 或微信中 `Ctrl+V` 或长按粘贴发送给家长！
   - 💾 **一键下载高清 PNG 长图**。
   - ✅ **支持盖印“已结清 PAID”水印**。
6. **轻量财务总览**：
   - 本月已授课时、预估总额、已收款与待收款统计看板。
   - 历史开单记录一览，支持一键切换已付/待付状态。

## 🚀 快速启动指南

### 方式一：双击启动（最简单）
在项目文件夹中，直接双击运行：
👉 **`start.bat`**
系统会自动启动本地服务并打开浏览器访问 `http://localhost:3001`。

### 方式二：命令行启动
打开终端（PowerShell 或 CMD）：
```bash
# 启动生产服务 (前后端一体化)
node server/index.js

# 或启动前端热重载开发模式
npm run dev
```

---

## 📱 手机如何连接使用？

1. 确保手机和电脑连接在同一个家庭或教学 Wi-Fi。
2. 在电脑命令行输入 `ipconfig` 查看电脑的 IPv4 地址（如 `192.168.1.100`）。
3. 在手机浏览器中输入：`http://192.168.1.100:3001`。
4. 提示：点击浏览器菜单中的**“添加到主屏幕”**，即可像原生 App 一样随时从手机桌面启动打卡！
